Privacy policy – Agent Village

Last updated: 30 October 2026

Agent Village is a personal, non-commercial tool used only by its owner (milansteen22@gmail.com). It is not offered to the public.

What data is accessed

With the owner's consent, the app uses the Gmail API scope gmail.readonly to read the sender, subject and text of new emails in the owner's inbox. It cannot send, delete or modify email.

How data is used

Email content is processed on the owner's own computer and sent to Anthropic's Claude (via the owner's own Claude account) to classify which emails are important. A short summary is sent to the owner's own Telegram chat. Nothing is used for advertising, sold, or shared with anyone else.

Storage

Email content is not stored. Only the time of the last run and a basic activity log are kept on the owner's computer.

Google API Services User Data Policy

Agent Village's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
